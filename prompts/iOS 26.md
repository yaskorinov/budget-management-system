### 1. ФИЗИКА И ПАРАМЕТРЫ МАТЕРИАЛА (LIQUID GLASS SPECS)

Каждая стеклянная поверхность должна обладать тремя физическими качествами:
1. Оптическая дисперсия и насыщенность: Фон под стеклом не просто размывается, а оптически конденсируется с усилением цвета (saturate 190% - 210%).
2. Фасетные зеркальные кромки (Specular Highlights): Верхняя грань преломляет внешний свет через яркую внутреннюю полупрозрачную линию, нижняя грань дает мягкий зеркальный контур.
3. Рассеянное пространственное парение: Никаких тяжелых черных теней. Тень многослойная, диффузная, с большим радиусом рассеивания.

CSS-формулы материалов:

```css
/* Светлая тема (Liquid Glass Light) */
.liquid-glass-light {
  background: linear-gradient(
    135deg,
    rgba(255, 255, 255, 0.55) 0%,
    rgba(255, 255, 255, 0.35) 100%
  );
  backdrop-filter: blur(40px) saturate(190%) contrast(105%);
  -webkit-backdrop-filter: blur(40px) saturate(190%) contrast(105%);
  border: 1px solid rgba(255, 255, 255, 0.65);
  box-shadow: 
    inset 0 1.5px 1px 0 rgba(255, 255, 255, 0.95),   /* Верхний фасетный скол */
    inset 0 -1px 1px 0 rgba(255, 255, 255, 0.25),   /* Нижний рефлекс */
    0 20px 40px -12px rgba(0, 0, 0, 0.07),          /* Основное парение */
    0 4px 12px -2px rgba(0, 0, 0, 0.03);            /* Контактная тень */
}

/* Темная тема (Liquid Glass Dark) */
.liquid-glass-dark {
  background: linear-gradient(
    135deg,
    rgba(32, 32, 38, 0.60) 0%,
    rgba(20, 20, 24, 0.70) 100%
  );
  backdrop-filter: blur(45px) saturate(210%) contrast(110%);
  -webkit-backdrop-filter: blur(45px) saturate(210%) contrast(110%);
  border: 1px solid rgba(255, 255, 255, 0.14);
  box-shadow: 
    inset 0 1.2px 1px 0 rgba(255, 255, 255, 0.30),  /* Верхняя фаска */
    inset 0 -1px 1px 0 rgba(0, 0, 0, 0.40),
    0 24px 48px -12px rgba(0, 0, 0, 0.55);
}
```

### 2. СИГНАТУРНЫЕ ПАТТЕРНЫ И КОМПОНЕНТЫ iOS 26

#### А. Плавающий навигационный остров (Inset Floating Dual-Island Bar)
- Навигационная панель снизу никогда не примыкает к краю экрана (no full-bleed).
- Она парит над контентом с отступами: bottom: 24px, left: 20px, right: 20px.
- Паттерн двух островов (Dual-Island):
  1. Основная капсула навигации: горизонтальная вытянутая плашка (rounded-full, padding ~8px 16px) с таб-кнопками и тонкими пиктограммами.
  2. Action Island (Остров действия): справа от капсулы с отступом 12px находится отдельный круглый парящий стеклянный остров (w-14 h-14 rounded-full flex items-center justify-center) для главного действия (Search, Create, Voice или AI Action).

#### Б. Верхняя парящая шапка (Floating Condensed Header)
- Заголовок и управляющие кнопки собраны в компактные плавающие стеклянные пилюли.
- Контент страницы при скролле уходит под шапку, визуально искажаясь и преломляясь сквозь толщу стекла.

#### В. Геометрия карточек (Continuous Squircles)
- Радиусы скругления концентрические:
  - Внешние карточки: border-radius от 28px до 36px (Tailwind: rounded-[32px]).
  - Внутренние вложенные элементы (превью, кнопки, бейджи): кривизна рассчитывается по формуле: R_inner = R_outer - padding.
- Никаких прямых углов 90° и никаких стандартных мелких радиусов 6px/8px.

#### Г. Сегментированные контроллеры (Liquid Segmented Sliders)
- Базовая дорожка контроллера: утопленный матовый трек (background: rgba(0, 0, 0, 0.06)).
- Активный ползунок (Thumb): выпуклая линза rounded-full с выраженной верхней фаской, плавно перемещающаяся с пружинной анимацией.

### 3. ТИПОГРАФИКА И СВЕТОВАЯ ИЕРАРХИЯ
- Семейство шрифтов: -apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", "Inter", sans-serif.
- Трекинг заголовков: Оптически плотный (letter-spacing от -0.025em до -0.035em), вес font-semibold (600) или font-bold (700).
- Иерархия текста:
  - Primary: #000000 (Light) / #FFFFFF (Dark).
  - Secondary: rgba(60, 60, 67, 0.72) (Light) / rgba(235, 235, 245, 0.65) (Dark).
  - Tertiary: rgba(60, 60, 67, 0.45) (Light) / rgba(235, 235, 245, 0.40) (Dark).
- Акцентные цвета: Динамические градиентные тинты с высокой оптической чистотой: iOS Blue (#007AFF), Cyber Mint (#00E5A3), Deep Violet (#5E5CE6).

### 4. МИКРОВЗАИМОДЕЙСТВИЯ И ПРУЖИННАЯ ФИЗИКА (SPRING PHYSICS)
- Нажатие (:active): Ощутимый тактильный прожим — transform: scale(0.96).
- Кривая анимации Apple Spring: 
  - transition: all 0.45s cubic-bezier(0.16, 1, 0.3, 1).
  - Никаких линейных переходов или дефолтных ease-in-out.
- Ховер-эффект: При наведении фасетный блик граней слегка меняет угол освещения (box-shadow мягко смещается в сторону курсора).

---

### 5. СТРОГИЕ НЕГАТИВНЫЕ ОГРАНИЧЕНИЯ (NEGATIVE CONSTRAINTS)
- ❌ НЕ использовать глухие непрозрачные фоны (bg-white, bg-black, bg-gray-100 без альфа-канала).
- ❌ НЕ прижимать Tab Bar к нижней границе экрана на 100% ширины. Навигация iOS 26 всегда парит островком с отступами.
- ❌ НЕ использовать грубые черные тени (box-shadow: 0 4px 6px rgba(0,0,0,0.3) запрещены). Тень обязана быть многослойной и полупрозрачной.
- ❌ НЕ делать плоские рамки. Бордер должен состоять из тонкой полупрозрачной границы в связке с внутренними тенями inset, имитирующими скошенное стекло.
