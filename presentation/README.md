# Презентация на защиту

`Общий бюджет — защита.pptx` — 9 слайдов по шаблону содержания хакатона,
собранные в фирменном визуальном шаблоне.

## Перед защитой заменить

1. **Название команды** — в `build_deck.py`, переменная `TEAM` (подставится
   на титул, в шапку каждого слайда и на финальный слайд).
2. **Роли участников** на слайде «Команда» — сейчас там заглушки «— роль —».

После правок пересобрать:

```bash
python presentation/build_deck.py
```

## Что откуда

* `assets/arch.png` — схема архитектуры, исходник рядом: `assets/arch.html`
  (правится в браузере, снимается скриншотом на 1400×620).
* `assets/screens.png` — коллаж трёх экранов мини-аппы.
* `assets/qr.png` — QR на репозиторий.
* `assets/ava-*.png` — плитки с инициалами вместо стоковых фото шаблона.

Визуальный шаблон и шаблон содержания лежат вне репозитория —
путь к ним задан в `build_deck.py` (`TEMPLATE`).
