# Иконки категорий

Положите сюда свои файлы — они заменят встроенные пиктограммы.

**Формат: SVG.** Он рисуется вектором прямо в диаграмму, поэтому не мылится
на любом размере. Разбирается атрибут `d` у `<path>` — команды M, L, H, V, C,
S, Q, T, A и Z, абсолютные и относительные. Заливка берётся своя (тёмная
`#1a1a19`), цвета и обводки внутри файла игнорируются: иконка должна читаться
силуэтом на пастельном фоне сегмента.

**Имена файлов** — по коду категории:

| Файл | Категория |
|---|---|
| `food.svg` | Продукты питания |
| `household.svg` | Бытовые мелочи |
| `utilities.svg` | Коммуналка |
| `subscriptions.svg` | Общие подписки |
| `goods.svg` | Общие предметы |
| `other.svg` | Прочее |

Файла нет — рисуется встроенная пиктограмма из `app/core/charts.py`.

Что учесть при подборе:

* иконка занимает примерно половину толщины кольца, поэтому тонкие штрихи и
  мелкие детали в ней теряются — лучше сплошные силуэты;
* сама вписывается в квадрат и центрируется, `viewBox` и размеры холста не важны;
* контуры с дырками (например, буква «о») работают, если внутренний контур идёт
  в обратную сторону — так их и экспортируют почти все редакторы;
* `<circle>`, `<rect>`, `<line>` не поддерживаются: переведите фигуры в контуры
  (в Figma — Flatten, в Illustrator — Object → Path → Outline).
